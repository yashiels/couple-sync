# GCP Infra — Implementation Plan (Plan B)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pin the Google Cloud / Firebase footprint for v1 — App Links hosting, App Check enforcement on the new client-write path, Calendar API quota/backoff, and runtime alignment. These protect the free-tier posture and make the device-written `overlaps/latest` path safe from abuse.

**Architecture:** Firebase Hosting serves the `/.well-known/` verification files at the root domain (no redirect, `application/json`). App Check (DeviceCheck on iOS, Play Integrity on Android) enforces Firestore writes + callable Functions, with a debug-token escape hatch for emulator builds. Calendar sync is throttled ≤ once/hour with exponential backoff on 429/503.

**Tech Stack:** Firebase Hosting, Firebase App Check, Cloud Functions v2 (nodejs22), Google Calendar API (freebusy), Flutter (`google_sign_in`, `googleapis`).

## Global Constraints

- App Link files must be served at exactly `/.well-known/apple-app-site-association` and `/.well-known/assetlinks.json`, content-type `application/json`, `Cache-Control: no-cache`, **no redirect** (a redirect breaks Universal Links).
- App Check enforcement must exempt emulator/`--use-emulator` builds via the debug token provider, or dev breaks.
- Calendar freebusy = 1 quota unit/call; device sync throttled ≤ 1 call/user/hour (existing `shouldAutoSync` 1h guard); exponential backoff on 429/503.
- Functions runtime: nodejs22 (done in Plan A Task 1; verify here).
- Conventional commits: `<type>(<scope>): <msg>`.

- [ ] **Step 2: Add exponential backoff to `fetchFreebusy`**

In `lib/services/calendar_service.dart`, wrap the `calendarApi.freebusy.query(request)` call in a retry loop:

```dart
Future<calendar.FreeBusyResponse> _queryWithBackoff(
  calendar.CalendarApi api,
  calendar.FreeBusyRequest request,
) async {
  int attempt = 0;
  const maxAttempts = 4;
  while (true) {
    try {
      return await api.freebusy.query(request);
    } catch (e) {
      final s = e.toString().toLowerCase();
      final retriable = s.contains('429') || s.contains('503') ||
          s.contains('rate') || s.contains('unavailable');
      attempt++;
      if (!retriable || attempt >= maxAttempts) rethrow;
      await Future.delayed(Duration(milliseconds: 500 * (1 << attempt))); // 1s, 2s, 4s
    }
  }
}
```

Replace the `final response = await calendarApi.freebusy.query(request);` line in `fetchFreebusy` with `final response = await _queryWithBackoff(calendarApi, request);`.
