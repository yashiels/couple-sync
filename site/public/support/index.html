Pairing with your partner

  1. One of you opens Couple Sync and taps Invite partner.
  2. Share the 6-character code however you like — a message, a call, a screenshot.
  3. The other opens the app and enters the code. You're paired.

Got an invite link?

Tapping a couple-sync.yashiel.dev/invite/… link opens the app if it's installed. If it isn't, the page shows the code — install the app, then type the code in. Codes expire after 48 hours; if yours has lapsed, just ask for a fresh one.

Calendar not syncing?

Couple Sync needs Google's free/busy permission, granted at sign-in. If you declined it, sign out and sign in again, making sure calendar access is allowed. The app only ever reads busy/free — never event details.

Contact

Something broken, or want your account and data removed? Open an issue on GitHub — that's the fastest way to reach me.
